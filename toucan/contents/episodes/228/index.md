description: "How do you give coding agents room to work without giving up control? Anna Eilertsen, a senior software engineer at Amazon, explains how she uses well-defined roles, tests, and independent validation to run teams of AI agents.

Anna joins Romain to discuss AI-native development. She covers creating prototypes, using agents to research unfamiliar codebases, and designing agents that can work in parallel while staying within clear boundaries.

Key topics covered:
  - Using traceable agent output to decide when to investigate a problem more deeply
  - Defining behavior and tests before asking an agent to implement a change
  - Using prototypes, feature flags, metrics, and logs to validate changes in production
  - Researching a feature across legacy and new system paths so a project can adapt when plans change
  - Creating focused agents with clear input, output, and permissions
  - Separating implementation from validation so an agent does not review its own work
  - Using agents to understand code, logs, metrics, and change history when joining a new codebase
  - Helping junior developers learn by asking questions, checking sources, and building judgment
