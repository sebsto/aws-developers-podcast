title: "AWS Emulator, AgentCore, Kiro: 10 updates you missed"
description: "What if your coding agent could test against AWS without an AWS account? No credentials, no bill, no waiting on a deployment.
No guest this time. Romain goes through the launches from the past month that change how you build on AWS, starting with AWS Emulator, a local emulator that agents built and maintain on their own.
Key topics covered:
  - AWS Emulator: a local emulator for the AWS CLI, SDKs and coding agents, how fidelity tests compare it with real AWS, and its limits (no IAM policy evaluation, single account)
  - How agents build and maintain the emulator, with an independent security agent reviewing every change
  - Amazon Bedrock AgentCore Runtime v2: sessions that start in under 2 seconds, up to 8 vCPUs and 30 GB of RAM, and idle agents that scale to zero
  - Kiro CLI 3.0: one agent harness across the CLI, IDE and web, workflows, cloud sessions and spec mode in the terminal
  - Bots in Kiro Crew: long-running agents that own one part of your process, with scoped permissions
  - AWS Step Functions workflows as agent tools, OAuth 2.0 token exchange in Amazon Cognito, and AWS Nitro sandboxes
  - The AWS Well-Architected Framework split into Cloud Foundations and Cloud Workloads, written so agents can run reviews
  - AWS Lambda Web Functions and AWS Continuum for Code Vulnerabilities
